# Customer-Personality-Analysis_marketing
Our project is an AI-driven marketing intelligence system that analyzes customer behavior, predicts churn, segments customers using machine learning, evaluates marketing campaigns, and provides business recommendations through interactive Power BI dashboards
Tools & Libraries: Python,Pandas,NumPy,Scikit-learn,Matplotlib,Seaborn,Power BI
Customer Personality Analysis dataset: https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis
Group members: Kossaly Diana & Temirov Madiyar
Key Marketing Findings: High-income customers generate the highest revenue
Campaign 4 and 5 showed the best conversion rates
Customers prefer Web and Store channels
